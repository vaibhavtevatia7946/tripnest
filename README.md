# 🧭 TripNest

A travel and ticket-booking website with animated sunset hero, sample flight/train/bus search, boarding-pass booking flow, and eight destination cards.

## Features
- Animated hero: rising sun, drifting clouds, flying plane, mountain layers
- Ticket search for Flights, Trains and Buses (sample data)
- Booking flow with boarding pass and confetti
- Destination cards styled as ticket stubs with animated scenes and filters
- Automatic dark mode and reduced-motion support

## Run locally
Open `index.html` in any browser. No build step or dependencies.

## Deploy with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.

## Tech
HTML, CSS and vanilla JavaScript in a single file.

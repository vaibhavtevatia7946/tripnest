## `~/ overview`

**TripNest** is a front-end travel booking concept engineered without the overhead of heavy frameworks or bundlers. It provides an interactive experience to discover eight curated destinations, compare schedules and sample fares across **flights, trains, and buses**, bookmark favorites locally, and generate a simulated boarding pass.

> **Note:** Schedules, fares, and boarding passes are illustrative mock records for UI demonstration. The application runs 100% client-side with zero external API latency.

## `~/ engineering & craft`

> *"Believes clean code and clean algorithms go hand in hand."*

- **Zero-Dependency Footprint:** Written entirely in semantic HTML5, modern CSS3, and vanilla JavaScript (ES6+). No node modules, bundlers, or compilation lag.
- **Sub-50ms First Contentful Paint (FCP):** Instant render with zero virtual DOM diffing or script hydration penalty.
- **Design Tokens Architecture:** Centralized CSS Custom Properties (variables) managing color palettes, typography scales, elevation shadows, and border radii.
- **Accessible by Default:** Structured semantic landmarks, distinct `:focus-visible` keyboard outlines, and native `prefers-reduced-motion` compliance.

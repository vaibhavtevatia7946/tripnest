# Contributing to TripNest

Thanks for helping improve TripNest. It is a static travel-booking demo with sample data; it does not create real bookings.

## Before opening a pull request

- Keep the project dependency-free and runnable by opening `index.html` in a browser.
- Check the flight, train, and bus search flows and the simulated boarding-pass flow.
- Confirm destination favorites still persist in the browser after a refresh.
- Check keyboard navigation, a narrow viewport, dark mode, and reduced-motion settings when changing the interface.

## Describe your change

In your pull request, summarize the user-visible change and list the manual checks you completed. Do not include real traveler information, booking details, or API credentials in this demo.
